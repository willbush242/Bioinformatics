# Bioinformatics and research tools

## Function

Retrieve and organise genome data, automate gene prediction, analyse experimental measurements and process microscopy images.

## Overview

A collection of Python, R, Bash and Fiji scripts developed during my university research. The tools cover data preparation, statistical analysis, visualisation and repeated processing tasks.

## Contents

Python scripts — Genome retrieval, assembly metadata, BUSCO summaries and filtering, protein-cluster analysis and iTOL annotations.

RStudio scripts — Statistical tests, group comparisons, plots and results export.

Bash scripts — Batch gene prediction with BRAKER, run in Ubuntu on WSL.

ImageJ macro — Automated channel processing, Z projections and composites from Nikon ND2 microscopy images in Fiji.

## Context and contribution

These scripts supported my third-year research into respiration in marine microorganisms and my final-year master's research into carbon-concentrating mechanisms in marine green algae at the University of Warwick.

Developed with assistance from ChatGPT. I defined the requirements, adapted and tested the code, checked outputs for errors, and debugged issues.

## How to use

Choose a category above, then follow the individual tool's README for dependencies, inputs and instructions. Replace placeholder paths and review the original research settings before using your own data. The scripts are separate tools; they do not all run as one pipeline.
